# Toxic Store Bot

A Telegram bot for selling Telegram accounts with automatic delivery, UPI/crypto payments, and referral system.

# Deploy Heroku Button ✅ 

[![Deploy to Heroku](https://www.herokucdn.com/deploy/button.svg)](https://heroku.com/deploy?template=https://github.com/harshkingxmdb/lnddd)

## Features

- 🛒 **Buy Accounts** - Purchase Telegram accounts from multiple countries
- 💰 **Add Funds** - Wallet system with UPI (auto) and Crypto (manual)
- 🎁 **Earn Money** - Referral system with ₹20 bonus on ₹1000 deposit
- 👤 **My Profile** - View balance, orders, and payment history
- 🔑 **Get OTP** - Retrieve OTP for purchased accounts
- 🔧 **Admin Panel** - Full control for owners

## Tech Stack

- Python 3.10+
- python-telegram-bot v20+
- Supabase (PostgreSQL)
- UPI/Crypto Payments

## Installation

1. Clone repository:
```bash
git clone https://github.com/sparshshivhare2007-pixel/SparshStoreBot.git
cd SparshStoreBot
```
2. Create virtual enviroments
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

3. install dependencies 
pip install -r requirements.txt

4. run 
python bot.py
